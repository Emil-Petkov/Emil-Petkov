<details>
<summary><strong><code>03 // DOCUMENTATION STANDARD</code></strong></summary>

<br>

Public technical work should make four elements clear:

**`OBJECTIVE`**  
What was being examined, built, validated, or understood?

**`METHOD`**  
What approach was used, and why?

**`EVIDENCE`**  
What observable results support the conclusion?

**`RESULT`**  
What was established, learned, validated, or produced?

<br>

```text
OBJECTIVE
    ↓
METHOD
    ↓
EVIDENCE
    ↓
RESULT
```

A reviewer should be able to follow the reasoning without relying on unstated context.

<br>

</details>
